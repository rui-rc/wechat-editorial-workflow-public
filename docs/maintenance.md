# 配置与维护

学院要求由维护者集中维护，编辑者只提供当篇事实和补充要求。

本仓库已内置湖南大学法学院配置。修改 `wechat-editorial-workflow/requirements/学院要求.md` 时维护适用账号、文字规范、品牌素材、署名和审核流程，并标明必须、建议或参考。素材放在要求文件旁的 `assets/`，使用相对路径。空白项不继承其他学院要求。
规范调整后用一篇非正式稿验证。升级导入器前检查接口、保存机制与图片持久化；当前同会话脚本针对安装说明指定的固定版本，不直接跟随上游最新版。

不要提交浏览器资料目录、Cookie、环境变量文件、真实稿件、个人日志或账号材料。运行产生的截图、备份及诊断记录留在使用者本地。向仓库添加机构素材前确认使用和分发范围。

更换品牌图片时同步更新brand-assets.json的来源、格式、尺寸和SHA-256。保留真实文件格式，动态素材不能用截图代替；不要由文件扩展名推断动画。编辑、校对、审阅是固定三级栏位，姓名和审核状态按当篇实际分工处理。
