# 模型选择依据

核对日期：2026-10-16。这里记录能力依据供维护者更新，PDF手册只保留简短建议，不加入链接。

- 千问 Qwen3.8-Max／Flash：阿里云官方列明视觉输入、函数调用与内置工具支持。[视觉理解](https://www.alibabacloud.com/help/en/model-studio/vision-model)。Max优先、Flash作为速度选项是结合本任务的建议，不是本项目的横向性能测评。
- Kimi K3：官方说明原生视觉、长上下文和长程任务能力。[Kimi K3官方介绍](https://www.kimi.com/news/kimi-k3)。据此列为图文材料及多步骤任务备选，不声称已经逐款验证秀米操作。
- 智谱 GLM-4.6V：官方列明多模态工具调用、图文布局、视觉搜索和前端视觉交互。[GLM-4.6V官方文档](https://docs.z.ai/guides/vlm/glm-4.6v)。推荐这个明确支持视觉的型号，不把所有GLM型号都当成视觉模型。
- GPT-6.1 Sol／GPT-6 Astra：OpenAI官方将Sol定位为兼顾速度、成本与能力，Astra用于更复杂任务，并说明computer use能力。[模型指南](https://developers.openai.com/api/docs/guides/latest-model)、[电脑操作指南](https://developers.openai.com/api/docs/guides/tools-computer-use)。Codex是承载工具和任务的Agent环境，不与GPT模型并列为同一种产品。

模型能力不等于宿主已支持相应工具，也不等于本项目兼容性验收。是否能读取本地文件、调用浏览器、持续执行，均应在实际环境检查。不同版本和供应商转接可能限制图像或工具输入，以实际界面及官方说明为准。审美偏好需用真实材料短样确认，不将官方通用能力描述写成美观度排名。

## GLM-5.3与DeepSeek-V4.1-Flash补充

- GLM-5.3官方文档明确为text-only inputs，支持函数调用；可承担规划和执行，但不能声称本体原生读图。[官方文档](https://docs.z.ai/guides/llm/glm-5.3)。GLM-5.3-Flash官方说明支持原生多模态与截图、图像理解，故手册将其列为视觉工作备选。[官方能力表](https://autoclaw.z.ai/models/)。本次手册以5.3／5.3-Flash取代较旧的4.6V推荐条目，保留上文4.6V来源仅供维护参考。
- DeepSeek-V4.1-Flash官方发布说明确认原生多模态视觉及Agent能力，并列明WorkBuddy／OpenCode接入。[发布说明](https://deepseek.com/news/deepseek-v4-1-flash/)、[Agent接入文档](https://api-docs.deepseek.com/guides/coding_agents/)。官方API型号为deepseek-flash；手册用产品全名避免普通用户误选旧版纯文本型号。
