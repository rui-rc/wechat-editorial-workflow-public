# 学院公众号排版工作流

面向学院公众号的文案整理、选材排版和秀米草稿制作。已内置15px正文、两端对齐、两字符缩进、两倍行距、左右5px及固定首尾。学院规范与执行流程分开维护，适合由维护者配置后交给编辑团队使用。

## 能做什么

- 根据活动材料写稿、改稿或审阅。
- 按学院要求处理文字样式、品牌素材与署名。
- 导入本地稿件和图片，保存为可继续编辑的秀米草稿。
- 在同一浏览器会话中复开检查、局部修改并再次保存。

## 开始使用

**第一次接触AI助手？先看 [问答手册 PDF](docs/用户问答手册.pdf) 或 [在线问答](docs/用户问答.md)。**

1. 阅读 [安装与首次使用](docs/setup.md)，准备 AI 助手和本地执行环境。
2. 查看已内置的 [湖南大学法学院要求](wechat-editorial-workflow/requirements/学院要求.md) ，按安装说明获取有权使用的固定品牌素材，并提供本篇编辑、校对、审阅人员。
3. 在 AI 助手中打开本仓库目录，发送：

> 请读取 wechat-editorial-workflow/SKILL.md，按照学院要求整理我提供的材料，制作可编辑的秀米草稿。登录、制作、保存和复核使用同一浏览器会话。遇到问题先定位处理，不擅自切换浏览器。

只需要文字时补充“本次只交付文案”；续改时提供草稿链接和允许修改的范围。

## 环境与边界

推荐入口为 Windows 桌面端 Codex。本地脚本依赖 Python 3.11+、Selenium 及固定版本的 all-to-xiumi。Chrome 路径已有验证；脚本提供 Edge 选项，部署时应先确认实际连接。其他浏览器需要单独适配。
浏览器由使用者选择，不要求统一品牌。制作全过程保持同一实例与登录会话，不迁移凭据。登录、账号资格和费用由相应服务管理。
保存草稿不等于审核或发布。发送审核消息、购买素材、公开发布需单独明确授权。

## 执行与质量

统一入口 `run_article.py` 维护本篇主稿和恢复记录，减少重复新建与临时脚本。基础生成采用独立可编辑组件，排版审计同时检查真实间距、正文角色、三层署名与图片比例。机器校验、真实手机预览和用户审美认可分别处理；详见 `wechat-editorial-workflow/references/reliability.md`。
