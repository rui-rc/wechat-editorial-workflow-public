# 秀米原生卡片

用户指定原生卡片，或原生素材更适合所需效果时，直接在当前秀米会话制作。自制HTML卡片不能冒充原生素材；静态截图不能冒充动效。

## 选材与插入

1. 在素材库打开实际分类，点击准确的菜单项。等待卡片列表出现；切换分类、提交搜索后，比对条目内容或模板标识是否变化。不以点击返回成功代替结果，不因一次搜索未生效断言没有素材。
2. 看真实缩略图，绑定同一条目的文字、模板标识和元素。不要使用历史列表下标、猜模板ID或混用另一条目的对象。权限与付费提示按原界面处理。
3. 先选定插入锚点。**文字光标必须退出，再选中组件**；否则原生粘贴可能从光标处拆开原段。`native_cards.select_component_anchor(driver, exact_text)` 可用于文字独立成块的顶层组件；嵌套卡片需要通过布局界面选择其整体，不能拿内部标题冒充整组。
4. 点击已核对的原生卡片，检查新增组件的实际内容、完整结构及位置。一个卡片可能由标题和正文等多个顶层组件组成，不能只认第一个组件。立即核对原段落未拆开、固定首尾未移位。

## 改字与复用

- 正文先按学院规范分成可独立编辑的块，原生卡片在块之间插入；不要把整篇文章塞进一个大文本组件后再拆。
- 按独立文本单元修改，保留原生装饰和布局。仅修改DOM文字并派发事件，可能看起来成功而保存回退；必须经过编辑器实际输入，再保存复开。
- 对唯一、单文本run的单元（含一层加粗等包裹），可用：

  ```python
  from native_cards import replace_native_text
  change = replace_native_text(driver, old_text, new_text, backup_path)
  save(driver)
  reopen(driver, expected_text=new_text)
  assert [c['html'] for c in snapshot(driver)] == change['expected_html']
  ```

  备份路径每次唯一。该函数拒绝重复文案、多run及包含图片、动效、换行等的混合单元；这些情况在同一界面中缩小选区处理，不强行全选重打。其HTML比对不覆盖外围布局和动效，仍需视觉与组件结构检查。
- 一张卡片合格后，优先用秀米原生复制/粘贴复用整组。刚插入时通常已选中整组，先核对组成部分，再使用工具栏“复制”，可避免改字后只选到某个内部单元。复制后及时在新锚点粘贴，不依赖刷新后仍存在旧剪贴板内容。每次粘贴后先改成唯一标题，再填写正文与编号，避免相同占位字定位到错误章节。编号重复时按其所在卡片缩小选区，不能全篇匹配第一个数字。
- 无法可靠选择整组时，可从“最近使用”或已核对分类重新插入同一模板；不反复搜索、不截成图片、不盲改内部组件数组。

## 验收与续改

先验证一个模块的插入、改字、保存复开，再展开全文。模板默认正文未必符合学院要求：字号、行距、缩进、实际留白需要局部校正；不能只因使用原生模板就豁免。原生复杂组件不适配基础审计器时，记录具体文字、样式、图片、组件边界和手机效果，不能为通过审计把它拆平。

保存复开比较原文与新文、邻近段落、组件数量/顺序、装饰与图源。动效或交互另行在真实预览验证，不能以静态图证明。已插入原生卡片的稿件不再整篇导入HTML；后续只局部修改。验证范围按本次真实模板记录，不宣称任意素材都已适配。
