# 可编辑视觉参考

这两组模块来自实际保存、复开和窄屏检查过的视觉试样，提供可复用的构图起点，不绑定任何学院。

当前附带两套参考，不要求先收集更多案例才能制作新设计。先按 [制作规则](../../references/design-execution.md) 推导本篇结构，必要时使用这些例子；自制HTML填妥后执行 [兼容预检](../../references/html-compatibility.md)。

- `commemorative.html`：纪念方向。数字、年份和主标题形成视觉中心，作者为辅助信息，章节呼应主色。
- `letter.html`：来信方向。左对齐两行主标题、浅色信笺与作者信息形成阅读顺序，章节使用细线。

仅在符合本篇意图时使用。执行者将`{{占位项}}`替换为已确认内容；缺少依据的数字和年份不编造，必要时删除对应装饰元素。标题长度须在实际窄屏复核。示例色彩与标题字号可按本篇修改，不作为机构规范。

模块只包括主视觉、辅助信息和章节，不含正文、品牌、图片或审核栏位。按当前要求组合这些内容；正文格式从当前规范取得。HTML输入使用现有导入路径，保存后检查样式与可编辑性；它们不是秀米原生模板，也不是机构官方纪念标识。已插入原生组件的稿件不得为使用这些模块而整篇覆盖。
