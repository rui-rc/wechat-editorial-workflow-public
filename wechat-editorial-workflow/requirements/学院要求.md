# 湖南大学法学院公众号要求

适用账号：湖南大学法学院。文字规范以本文件为准；参考文章只确定品牌资产、署名栏位和相关样式，不以参考文章局部样式覆盖明确要求。

## 正文规范

| 项目 | 要求 | 验收依据 |
|---|---|---|
| 字号 | 15px | 实际正文及其内联文字均为15px |
| 对齐 | 两端对齐 | text-align:justify |
| 首行缩进 | 两个汉字 | 优先text-indent:2em，15px时计算值30px |
| 手动缩进 | 仅允许两个全角空格U+3000 | 与CSS缩进二选一，不能叠加；半角空格不合格 |
| 行间距 | 2倍 | 计算行高30px |
| 字间距 | 推荐0px或1px，默认0px | 不沿用参考文章的2px等其他值 |
| 左右边距 | 各5px | 仅在文章内容容器设置；内部和祖先不额外叠加留白 |
| 段落间隔 | 两段正文之间空一行 | 以一个30px间隔实现；不叠加空白段落和多重margin |
| 图文间隔 | 依内容适当调整段前距、段后距 | 与段落间空一行区别处理，不靠连按回车堆空白 |

标题、图片、图注和文末署名有各自角色，不套用正文首行缩进和两端对齐。标题层级由内容决定，“三级”专指审核栏位，不能据此强制三级标题。
正文卡片、引用和清单中的正常叙述文字同样遵守正文要求；需要例外时由本次用户明确指定。

三行署名紧邻末图上方，之间不插入其他图片、正文或空白段落。最后两个品牌视觉对象不可合成一张图，否则署名位置无法正确保留。

## 三级审核与署名

固定三层栏名和顺序为：**编辑 → 校对 → 审阅**。不自行更名为初审／复审／终审，也不增删一层。默认保留参考排版：14px、居中、行高1.6、无首行缩进，分隔符统一为“｜”。

人员按本篇实际分工填写，不能把历史编辑者冒充当前编辑者。参考资料：首篇为“编辑｜龚钰涵、校对｜曹晓军、审阅｜蒋海松”；第二篇为“编辑｜李小雪、校对｜董轩萌、审阅｜蒋海松”。人员不同说明固定的是栏位和位置，名单不是跨文章自动事实。
用户明确指定沿用参考名单时可使用其指定版本；正式稿缺名单时询问缺项，其余制作继续。试稿使用明确测试署名。填写了名字不代表已经审核，三级状态应分别依据实际审批证据记录；不得自动对外发送或发布。

## 其他事项

标题、摘要、署名以外的作者／摄影信息、封面裁切及审核后流转按当篇材料执行。未明确之处不套用其他学院的旧规范。
